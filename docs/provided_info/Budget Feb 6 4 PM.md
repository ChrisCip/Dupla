DEFINICIÓN DEL EXCEL:  
El Excel es una presentación del presupuesto de obra que se genera desde el sistema Presto. Se utiliza para revisión interna de gerencia y envío al cliente. El presupuesto está organizado por partidas y muestra los costos de construcción de manera detallada.

ELEMENTOS Y DIVISIÓN:  
El presupuesto se divide en:

* Por Partidas Principales:  
  * Trabajos preliminares (fumigación, limpieza, topografía, replanteo)  
  * Costos indirectos  
  * Acondicionamiento del terreno  
  * Estructura general  
  * Obra gris (hasta dejar la casa en gris, sin terminaciones)  
  * Instalaciones (preinstalaciones eléctricas, sanitarias, aire)  
* Por Zonas/Bloques:  
  * Se divide por estación principal, oficina, bloques separados  
  * Esto facilita identificar y realizar cambios según las modificaciones del cliente  
* Por Niveles:  
  * Nivel 0, primer nivel, segundo nivel, etc.  
  * Cada nivel contiene: movimiento de tierra, hormigón armado, muros, vigas, losas  
* Por Unidades de Medida:  
  * Metro cuadrado (m²)  
  * Metro lineal (ml)  
  * Metro cúbico (m³)  
  * Unidades mensuales (personal)  
* Elementos Específicos:  
  * Piscina, jacuzzi, espejos de agua (separados para que el cliente pueda decidir incluirlos o no)  
  * Obras civiles complementarias  
  * Áreas exteriores

FUENTE DE INFORMACION:  
Presto, pero se pasa al cliente en excel para que pueda enviárselo. ( Oportunidad de automatización de generación )
